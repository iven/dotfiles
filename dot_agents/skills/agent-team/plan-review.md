# 方案评审流程

1. 主持人收到方案后，需要为每个专家在 Raft 上分别建立 Task，在任务描述中给出以下信息：
  - 仓库地址/路径
  - 需求文档链接
  - thread 消息 ID，以便专家拿到原始方案
  - 提及本 Skill，以便让专家按本 Skill 进行处理
  常见的错误是自己将方案总结到 Task 描述中，既无必要也会丢失信息。
2. 专家收到任务后直接认领，并开始按照角色文档中提及的范围进行 Review，并在 Task 中与开发者进行讨论，直到达成一致。
3. 如果方案有重大变更，开发者应该立即停止讨论，并在 thread 中更新方案，并在 Task 中告知专家们，以免针对旧的无效方案进行讨论。
4. 所有 Task 讨论一致后，由开发者将最终方案发到 thread 中，寻求用户通过。
5. 用户通过后，主持人关闭这些评审任务。
