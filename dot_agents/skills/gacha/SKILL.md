## 概述

卡片位置在 `~/Dropbox/Notes/Gacha/memory/日本語/`，卡片格式参见 skill 同目录下的 `format.md`。

以下为常用操作。

## 获取音调

拿音调执行 `scripts/get_pitch_accent.sh <词> [词...]`，脚本内部已固定查询命令：

```bash
scripts/get_pitch_accent.sh 訪ねる たずねる
```

使用规则：

- 同时尝试汉字表记和假名表记；对纯假名词，也尝试常见汉字表记。
- `◎` 必须规范化为 `⓪`；其他数字保持原样，如 `③`。
- 存在多个候选时，保留多个候选。
- 页面无结果或候选无法判断时，告知用户拿不到确定音调，不凭印象推断，也不需要去其他网站查询。
- 如果涉及到了动词活用型的音调，可以读取 `accent.md` 中的规则。

## 创建

卡片内容必须严格遵循格式文档。创建卡片前禁止读取现有其他卡片的完整内容，防止被其内容污染上下文，导致新创建的卡片格式与文档规定不符。

使用 `scripts/create_card.py` 创建卡片基本 frontmatter，然后按照卡片格式书写正文，正文和 frontmatter 之间空一行。

对于正文内容不确定的释义、区别等，可以进行浅度搜索，确定则不需要搜索。

新卡生成/修改后跑格式检查，全部通过才算完成：

```bash
scripts/check_card.sh <文件路径>
```

检查报出问题时按下面处理：

- 残缺注音：补全 `{基底|读音}`。
- 注音块外残留汉字：漏标的汉字补注音（`[自][他][名]` 等词性标注除外）。
- 粗体贴字：`**` 两侧补半角空格。
- 注音块基底含假名：假名（含送假名）留在块外，如 `{水たまり|みず・たまり}` 改为 `{水|みず}たまり`。
- 注音切分段数与基底字符数不一致：「・」按汉字切分读音，段数应等于基底汉字/数字数
  - 超过说明把单个汉字的读音拆开了，如 `{受付|う・け・つけ}` 应为 `{受付|うけ・つけ}`
  - 少于说明整段覆盖多字，须查词典核对
  - 熟字訓等拆不开的（如 `{今日|きょう}`）保留
- 连续引用块：两条 `>` 引用之间留空行。

以上只检查格式，需要额外检查一下正文的内容、格式、读音等是否有明显错误，意思是否有重复，是否有循环释义，是否涵盖了必要的知识点，例句是否过于简单，如果有问题则修正。

最后，输出卡片的中文释义（包括例句），无需输出 QC 结果等其他内容。

## 搜索

卡片正文带注音块，汉字和假名被 `{}`、`|` 拆开，连续写法（`過ごす`・`渡る`・`きにいる`）直接搜会漏；先搜汉字或块内假名片段，需要精确定位时用转义后的块格式：

```bash
rg -l '過|渡|かよ' <目录或文件>              # 按片段搜，不易漏
rg -n '\{過\|す\}ごす' <目录或文件>          # 精确搜某个词条
```

- 花括号、竖线要转义：`\{`、`\|`
- 纯假名词（ある・いる）直接搜假名即可命中
- 搜索范围可以是单个文件，也可以是整个分类目录
