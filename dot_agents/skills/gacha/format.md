# Gacha 卡片文案创建原则

## 注音语法

格式：`{基底|读音}`。

- **单字组合**：`{倒|たお}`——整组覆盖，读音内部连写，不用「・」
- **多字组合**：`{地震|じ・しん}`——按字分配，不同字符的读音之间用中点「・」分隔
- **假名不进注音块**：基底只放需标音的汉字，假名（含送假名）留在块外。`{水|みず}たまり`・`{祭|まつ}り`，不是 `{水たまり|みず・たまり}`・`{祭り|まつり}`

注意：同一个词汇，使用同一个注音块，比如不要拆成 `{地|じ}{震|しん}`

## 音调标注

音调跟在词后；词性用方括号接在音调后。

写法：`{遺跡|い・せき} ⓪ [名]`，`{遅|おそ}い ②⓪ [形]`，`{起|お}きる ② [自]`，`{起|お}こす ② [他]`。

词性缩写：名词 `[名]`、代词 `[代]`、イ形容词 `[形]`、ナ形容词 `[形動]`、副词 `[副]`、接续词 `[接]`、连体词 `[連体]`、自动词 `[自]`、他动词 `[他]`、助词 `[助]`、感叹词 `[感]`。

词性多个时用「・」连接：`{受|う}ける ② [自・他]`，`{渋滞|じゅう・たい} ⓪ [名]`。只标词性，不标活用型（自五・他サ 等不写）。

## 粗体使用

中日文里用 Markdown 粗体有个陷阱：`**` 后紧跟标点（包括 `{` 注音标记）时，前面必须是**空白或标点**才能开启粗体。因此在 `**` 前后必须加半角空格。例：

```
ビルが **{倒|たお}れて** しまいました
```

**何处加粗**（按重要性优先级）：

- 对照 / 对比的双方（自他动词对、类义词组、复合词与基础词等） → 强化对比
- 例文里的目标词 → 一眼锁定学习焦点
- 文法点的语法名（〜のために 等）→ 与释义视觉分离

**不加粗**：一级标题（已有视觉权重）、基础释义、修饰语。

## 紧凑性

卡片空间有限。原则：

- **小标题与内容一行，用冒号分割**（意味、関連、文法等），用正文字体即可，不使用括号等进行强调。
- 单行渲染宽度控制在 80 列以内（注音块取基底、`**` 不计、全角 2 列半角 1 列）
- 用 ⇆ 等符号简化表达
- 相似的知识点不要重复表达
- **正文不超过 7 行**（不含空行）＝目标值，不是硬约束

虽然卡片紧凑很重要，但绝不可以为了紧凑而牺牲排版结构性：每个知识点独立成行，单行超宽时拆行，不得为凑行数而将不同内容强行写在一行。

## 全日语原则

整张卡片用日语写（沉浸式学习）。

汉字注音覆盖范围：所有汉字都必须标。

写法以实际使用为准：口语/日常常用假名的词就写假名（ある・いる・いい），不用词典词目的汉字形（有る・居る・良い）；汉字形仅在同音需区分时用（要る⇄居る）。

## 例文设计

- 自然且包含目标词
- **必须顺带覆盖其他高频 N3/N4 语法点 / 词汇**：一句例文让学习者一次接触多个知识点，避免单点学习
- **使用从句和变形**：通过从句和变形来扩展知识点
- **真实场景优先**：职场、问路、点餐、电话等可直接套用的说法
- 长度不超过 1-2 行
- 难度：N4 → N3
- 例文里的目标词加粗

**正面例子✅**「もっと」：すみません、{聞|き}こえなかったので、**もっと** {大|おお}きい{声|こえ}で{言|い}ってもらえませんか。
→ 过去式、可能型、ので、～てもらえませんか（N4 知识点）

**反面例子❌**：**もっと** ゆっくり{話|はな}してください。
→ 例子太过简单，不涉及 N3/N4 中高级知识点，不具备词汇以外的教学价值

## 教学价值（最关键）

**篇幅优先给语法点 / 注意事项，少堆积拓展词汇**：列 4-5 个类义词记忆价值低；具体语法 / 用法 / 搭配规则才是核心。

一张卡能让学习者「举一反三」，比单纯「背一个词」价值高 10 倍。

思维方式：找词与词之间的关系——类义、反义、同音不同调（最小对）、自他对应、词族（生きる / 生まれる / 命）、敬语级别（言う / 申す / おっしゃる）、多义词的核心义、汉字的音训对比……让关系本身成为知识点。具体方向按词制宜，不局限于此处列举。如果存在明显对比，优先建对比卡片。

## 各种格式的用法

- **一级标题** `#` —— 仅用于单词卡的词条（详见「音调标注」）
- **三级标题** `###` —— 非单词卡（如对比卡）若需要标题时使用；不需要时首行用段落即可
- **注音** `{基底|读音}` —— 假名标注（详见「注音语法」）
- **粗体** `**...**` —— 对照 / 强调（详见「粗体使用」）
- **无序列表** `-` —— 列举语法点、对照词组、类义词
- **段落** —— 释义
- **引用块** `>` —— 例句（不加"例："前缀）。多个例句之间留空行。

其他格式（斜体 / 粗斜体 / 二级标题 / 代码块）暂不使用。

## 卡片示例

### 对比卡片

有自他・类义・反义等明显对比时，优先用这种；无明显对比的词才建主题卡。

```markdown
### {倒|たお}れる ② [自] ⇄ {倒|たお}す ② [他]

- **{倒|たお}れる** ② [自]：{立|た}っているものが{横|よこ}になる
- **{倒|たお}す** ② [他]：{立|た}っているものを{横|よこ}にする
- {主語|しゅ・ご}：**{倒|たお}れる**＝ビル・{木|き}が ⇄ **{倒|たお}す**＝{人|ひと}が〜を

> {地震|じ・しん}のために、できたばかりのビルが **{倒|たお}れて** しまいました。

> {子|こ}どもが{積|つ}み{木|き}を **{倒|たお}して** しまいました。

- **〜ために**：{原|げん}{因|いん}／**〜てしまう**：{残念|ざん・ねん}な{気持|き・も}ち
```

优点：

* 假名、词性都完整标记
* 对比的每个词汇都有例句，例句涉及其他知识点

缺点：

* 自他对比单独占了一行，没有必要

### 主题卡片

无明显对比的词汇、句式，可以用这种。

```markdown

# {横浜|よこ・はま} ⓪ [名]

{意味|い・み}：{東京|とう・きょう}の{隣|となり}にある{港町|みなと・まち}。{神奈川県|か・な・がわ・けん}の{中心|ちゅう・しん}。

- **{横浜|よこ・はま}に{住|す}む**＝{東京|とう・きょう}へ{通|かよ}える{町|まち}として{人気|にん・き}
- **{横浜中華街|よこ・はま・ちゅう・か・がい}**＝{中華料理|ちゅう・か・りょう・り}で{有名|ゆう・めい}な{場|ば}{所|しょ}

> {週末|しゅう・まつ}、**{横浜|よこ・はま}** の{中華街|ちゅう・か・がい}で、{食|た}べ{歩|ある}きました。
```

优点：

* 拓展了常用搭配
* 例句拓展了 `食べ歩く` 地道词汇

缺点：

* 没有对 `食べ歩く` 进行解释

### 其他卡片（自由发挥）

```markdown
### {子|こ}/{小|こ} + {動物|どう・ぶつ}

- **{小鳥|こ・とり}** ⓪ [名]（小）⇆ {鳥|とり} ⓪ [名]
- **{子猫|こ・ねこ}** ⓪ [名]（子）⇆ {猫|ねこ} ① [名]
- **{子犬|こ・いぬ}** ⓪ [名]（子）⇆ {犬|いぬ} ② [名]
```
